# Advanced Algorithms – PhD

This repository contains MATLAB implementations of numerical algorithms and matrix computation methods developed as part of the **Advanced Algorithms** course.

## Topics Covered

### 1. Matrix Computations
- Forward Substitution
- Backward Substitution

### 2. Gaussian Elimination Methods
- Gaussian Elimination
- Gaussian Elimination with Partial Pivoting
- Gaussian Elimination with Complete Pivoting

## Programming Language
- MATLAB
- Compatible with GNU Octave
